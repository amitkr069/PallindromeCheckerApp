### USE CASE: 06 

#### Implemented Stack and Queue for checking Palindrome CONCEPTS: 
Queue – A linear data structure that follows the First In First Out (FIFO) principle. 
Enqueue & Dequeue Operations – Used to insert and remove elements from the queue. 
Stack vs Queue – Demonstrates the difference between LIFO and FIFO structures. 
Logical Comparison – Taking out 1 character at a time from both stack and queue and comparing the results.
